# 🎬 Video Download Manager v2.0

افزونه پیشرفته کروم برای دانلود چند رشته‌ای (Multi-threaded) لینک‌های ویدیویی با قابلیت Pause/Resume

## ✨ ویژگی‌ها

### ویژگی‌های اصلی
- 🔍 **اسکن خودکار صفحه**: استخراج تمام لینک‌های دانلود ویدیوهای MKV و MP4
- 📊 **گروه‌بندی هوشمند**: دسته‌بندی ویدیوها بر اساس فرمت، کدک و کیفیت
- 🎯 **فیلتر پیشرفته**: جستجوی سریع بر اساس فرمت (MKV, MP4)، کدک (x265, x264) و کیفیت (1080p, 720p, 480p)
- ☑️ **انتخاب چندگانه**: انتخاب چندین فایل با چک‌باکس
- 🎨 **رابط کاربری زیبا**: طراحی مدرن و کاربرپسند با پشتیبانی از زبان فارسی

### ویژگی‌های جدید v2.0 🆕
- ⚡ **دانلود چند رشته‌ای (Multi-threaded)**: دانلود هر فایل با 4 رشته موازی برای سرعت بیشتر
- ⏸️ **Pause/Resume**: امکان توقف و ادامه دانلود در هر زمان
- 📈 **نمایش پیشرفت دقیق**: مشاهده پیشرفت هر chunk به صورت جداگانه
- 🚀 **نمایش سرعت دانلود**: مشاهده سرعت لحظه‌ای دانلود
- 📥 **صفحه مدیریت دانلودها**: مدیریت تمام دانلودها در یک صفحه مجزا
- 💾 **بهینه‌سازی حافظه**: استفاده بهینه از RAM با تقسیم فایل به چند بخش
- 🔄 **دانلود خودکار**: ادامه خودکار دانلودهای متوقف شده

## 📋 فرمت‌های پشتیبانی شده

- **ویدیو**: MKV, MP4, AVI, MOV, WMV, FLV, WebM, M4V
- **کدک**: x265 (HEVC), x264 (AVC), AV1, VP9, XviD
- **کیفیت**: 2160p (4K), 1440p (2K), 1080p, 720p, 480p, 360p, 240p

## 🚀 نصب و راه‌اندازی

### مرحله 1: دانلود افزونه

```bash
git clone <repository-url>
cd dotest
```

### مرحله 2: ایجاد آیکون‌ها (اختیاری)

آیکون‌ها به صورت خودکار ایجاد شده‌اند، اما در صورت نیاز می‌توانید دوباره آن‌ها را بسازید:

```bash
npm install
node generate-icons.js
```

یا از طریق مرورگر:
1. فایل `create-icons.html` را در مرورگر باز کنید
2. روی دکمه‌های "دانلود" کلیک کنید
3. فایل‌ها را در پوشه `icons/` ذخیره کنید

### مرحله 3: نصب افزونه در کروم

1. مرورگر گوگل کروم را باز کنید
2. به آدرس `chrome://extensions/` بروید
3. گزینه "Developer mode" را در گوشه بالا سمت راست فعال کنید
4. روی دکمه "Load unpacked" کلیک کنید
5. پوشه پروژه را انتخاب کنید
6. افزونه نصب شد! ✅

## 📖 نحوه استفاده

### استفاده پایه

1. به یک سایت دانلود ویدیو بروید (مثلاً سایت‌های دانلود فیلم یا سریال)
2. روی آیکون افزونه در نوار ابزار کروم کلیک کنید
3. روی دکمه "🔍 اسکن صفحه" کلیک کنید
4. منتظر بمانید تا لینک‌های ویدیویی استخراج شوند
5. ویدیوهای مورد نظر خود را با چک‌باکس انتخاب کنید
6. روی دکمه "⬇️ دانلود" کلیک کنید

### استفاده از فیلترها

افزونه فیلترهای مختلفی برای سهولت جستجو ارائه می‌دهد:

- **همه**: نمایش تمام ویدیوها
- **MKV**: فقط فایل‌های MKV
- **MP4**: فقط فایل‌های MP4
- **x265**: ویدیوهای با کدک x265 (فشرده‌تر و کیفیت بهتر)
- **x264**: ویدیوهای با کدک x264
- **1080p**: ویدیوهای Full HD
- **720p**: ویدیوهای HD
- **480p**: ویدیوهای SD

### دانلود دسته‌ای

1. از فیلترها استفاده کنید تا ویدیوهای مورد نظر را پیدا کنید
2. روی دکمه "انتخاب همه" کلیک کنید تا تمام ویدیوهای نمایش داده شده انتخاب شوند
3. یا به صورت دستی ویدیوهای دلخواه را انتخاب کنید
4. روی دکمه "⬇️ دانلود" کلیک کنید
5. صفحه مدیریت دانلودها به صورت خودکار باز می‌شود

### مدیریت دانلودها (v2.0) 🆕

#### مشاهده پیشرفت دانلودها
1. روی دکمه "📥 دانلودها" در popup کلیک کنید
2. صفحه جدیدی با لیست تمام دانلودها باز می‌شود
3. هر دانلود شامل:
   - نام فایل و حجم
   - نوار پیشرفت کلی
   - نوار پیشرفت هر chunk (4 بخش)
   - سرعت دانلود لحظه‌ای
   - وضعیت (در حال دانلود، متوقف، تکمیل شده، خطا)

#### Pause/Resume دانلود
1. برای متوقف کردن دانلود، روی دکمه "⏸️" کلیک کنید
2. برای ادامه دانلود، روی دکمه "▶️" کلیک کنید
3. برای لغو دانلود، روی دکمه "❌" کلیک کنید

#### مزایای دانلود چند رشته‌ای
- ⚡ سرعت دانلود تا 4 برابر سریعتر
- 💾 مصرف بهینه RAM با تقسیم فایل
- 🔄 قابلیت Resume در صورت قطع اینترنت
- 📊 نمایش دقیق پیشرفت هر بخش

## 🎯 مثال‌های کاربردی

### مثال 1: دانلود یک سریال کامل با کیفیت 1080p x265

1. به صفحه دانلود سریال بروید
2. افزونه را باز کنید و صفحه را اسکن کنید
3. فیلتر "x265" را انتخاب کنید
4. فیلتر "1080p" را اضافه کنید (با کلیک روی آن)
5. "انتخاب همه" را بزنید
6. دانلود کنید

### مثال 2: دانلود فقط فایل‌های MP4 با حجم کم

1. صفحه را اسکن کنید
2. فیلتر "MP4" را انتخاب کنید
3. فیلتر "720p" یا "480p" را انتخاب کنید
4. فایل‌های مورد نظر را انتخاب و دانلود کنید

## 🔧 توسعه و سفارشی‌سازی

### اضافه کردن فیلترهای جدید

برای اضافه کردن فیلترهای جدید، فایل `popup.html` را ویرایش کنید:

```html
<button class="filter-btn" data-filter="YOUR_FILTER">نام فیلتر</button>
```

### تغییر الگوریتم گروه‌بندی

تابع `groupVideos()` در فایل `popup.js` را ویرایش کنید:

```javascript
function groupVideos(videos) {
    // منطق گروه‌بندی خود را اینجا بنویسید
}
```

### اضافه کردن فرمت‌های جدید

در فایل `content.js`، regex زیر را ویرایش کنید:

```javascript
const videoExtensions = /\.(mkv|mp4|YOUR_FORMAT)(\?|$|#)/i;
```

## ⚠️ نکات مهم

1. **مجوزها**: افزونه به مجوز دسترسی به تمام سایت‌ها نیاز دارد تا بتواند لینک‌ها را استخراج کند
2. **محدودیت دانلود**: مرورگر ممکن است برای دانلود همزمان چندین فایل هشدار بدهد - آن را تایید کنید
3. **سایت‌های محافظت شده**: برخی سایت‌ها از لینک‌های محافظت شده استفاده می‌کنند که ممکن است قابل استخراج نباشند
4. **عملکرد**: در صفحات با لینک‌های بسیار زیاد، اسکن ممکن است کمی زمان‌بر باشد

## 🐛 رفع مشکلات

### افزونه لینک‌ها را پیدا نمی‌کند

- مطمئن شوید که در صفحه‌ای هستید که واقعاً لینک دانلود دارد
- دکمه "🔄 بروزرسانی" را بزنید
- صفحه را Refresh کنید و دوباره امتحان کنید

### دانلود شروع نمی‌شود

- بررسی کنید که مرورگر مجوز دانلود را داده باشد
- Pop-up blocker را غیرفعال کنید
- مجوزهای افزونه را در `chrome://extensions/` بررسی کنید

### افزونه نصب نمی‌شود

- مطمئن شوید Developer mode فعال است
- آیکون‌ها را با استفاده از `create-icons.html` ایجاد کنید
- مرورگر را ببندید و دوباره باز کنید
